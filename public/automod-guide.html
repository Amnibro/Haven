AMNI-HAVEN · AUTOMOD QUARANTINE v1.4.0

Quarantine links before anyone clicks them

AutoMod Quarantine is a security plugin for Haven servers. It isolates every unverified link in a non-clickable capsule, sweeps every new link on your own hardware the moment it is posted, processes multi-link bursts 1-at-a-time in a GPU-safe queue, blacklists malicious domains automatically, and unloads your local AI model from VRAM/RAM the instant scanning finishes.

What it does

Instant Link Quarantine

Intercepts markdown and raw URLs (including bare root domains and HTML-escaped query strings) at render time and replaces them with a safe quarantine capsule.

Context + URL AI Scan

Evaluates both the message text (e.g. “claim your free gift before it expires”) and the target domain against your server rules using local Ollama, Cloud APIs, or Subscriber SSO.

On-Demand Load & Unload

Wakes up your local Ollama model only when links are queued, scans them 1-at-a-time, and unloads the model from GPU VRAM / RAM (keep_alive: 0) as soon as the queue empties.

0ms Domain Blacklisting

When a link is flagged as malicious, its host is automatically added to blockedDomains. Remaining or future links to that domain are blocked in 0 ms without calling the AI again.

How the pipeline works

  1. Stage 1 — Intercept & Isolate: Every link posted in chat is wrapped in a non-clickable Quarantine Capsule before it reaches the screen.
  2. Stage 2 — 0 ms Source Trust Gate: Trusted domains (GitHub, Wikipedia, YouTube, Steam, etc.) are released immediately. Raw IP links, punycode homoglyphs (xn--), dangerous executables (.exe, .scr, .bat), known scam patterns, and previously blacklisted domains are blocked in 0 ms without touching the AI.
  3. Stage 3 — Automatic Server Sweep: The moment a message is posted, your Haven server queues its unverified links for the local AI, one at a time, and checks them against your server rules. By the time anyone opens the message the verdict is usually waiting (Queued (#1)..., Queued (#2)... while it isn’t).
  4. Stage 4 — Verdict, Auto-Blacklist & Strike: Safe links unlock in place with a verified badge (🛡️✓). Malicious links turn into a red Blocked Card, blacklist the offending domain, and issue a deduplicated channel strike warning.

Queueing, auto-blacklisting & GPU/RAM unloading

If someone pastes 10 links in a single message (or a raid floods a channel), running 10 LLM calls in parallel would spike GPU VRAM and system RAM. AutoMod Quarantine prevents this with three mechanisms:

  • One GPU queue on the Haven server: The automatic sweep and every moderator share a single queue on your server, so only one link reaches the model at a time no matter how many people are online. Links already checked are answered from the server’s cache without touching the GPU. Waiting capsules show their live position (Queued (#1)..., Queued (#2)...).
  • Mid-burst domain blacklisting (autoBlacklistBadHosts: true): If link #1 in a 10-link spam burst points to scam-drop.org/page1 and the AI flags it, scam-drop.org is blacklisted immediately. Links #2 through #10 on scam-drop.org are caught by the 0 ms Source Trust check as they pop off the queue—never calling the GPU/LLM again.
  • Load on queued links, unload on completion: While links remain in the queue, the server passes keep_alive: "2m" so Ollama keeps weights warm between back-to-back links. When the queue empties it calls /api/generate with keep_alive: 0, instructing Ollama to evict the model from GPU VRAM and RAM immediately.

Steps to set it up

  1. Run the automatic hardware setup on your Haven server. From your Haven server checkout, run one command. It inspects your GPU VRAM (NVIDIA, AMD ROCm/sysfs, or Apple Silicon), CPU cores, and system RAM, installs and starts Ollama if needed, pulls the best model for your hardware tier, and writes config/automod-local.json. No restart needed: from then on Haven sweeps every new link automatically. 
    git pull && ./scripts/setup-automod-ai.sh --install-ollama --pull
    Checkout without the script? Fetch it with Git and point it at your Haven folder: 
    git clone --depth 1 -b amni/live https://github.com/Amnibro/Haven.git /tmp/haven-automod && \
  /tmp/haven-automod/scripts/setup-automod-ai.sh /path/to/haven --install-ollama --pull && \
  rm -rf /tmp/haven-automod
    The automatic sweep runs inside the Haven server, so it needs a Haven build with the AutoMod engine (Amnibro/Haven amni/live). On other builds the script still installs the plugin and tells you what to update.
  2. Enable AutoMod Quarantine in Haven. Open Haven in your browser or desktop app › Settings › Plugins & Themes › toggle AutoMod Quarantine to ON. On startup the plugin finds your server’s local AI and switches to This Haven Server (Local AI), so every moderator uses your machine’s model from any device, phones included. No keys, no ports to open.
  3. Change the model or rules (Optional). Click the 🛡️ AutoMod button in the top header:
    • Model: The setup script picks the server’s model. To force one, re-run it with ./scripts/setup-automod-ai.sh --model=qwen3.6:35b-a3b --pull. For cloud providers, pick from Model Name: any recommended preset (qwen3.8:27b, qwen3.6:35b-a3b, granite4.2:8b, granite4:7b-a1b-h, qwen3.5:0.8b), or type any custom model tag. You can also force a specific model from the CLI with ./scripts/setup-automod-ai.sh --model=qwen3.6:35b-a3b --pull.
    • Auto-Detect Local AI: Click 🖥️ Auto-Detect Local AI at any time to re-check your Haven server’s AI (and, as a fallback, Ollama on the device you’re using).
    • Server Rules: When an admin saves the Server Rules box, the server AI checks every link against those rules for everyone.
    • Unloading: The server unloads its model whenever the queue is empty, so your GPU is free between scans. The “Load on queued links & unload” checkbox does the same for a direct Ollama connection.
  4. Test your connection. Click 🔌 Test AI Connection to run a live verification probe and see the exact verdict and latency.

Moderator controls & false-positive recovery

  • ⚠️ Warn User: Issues a formal strike and posts a customizable warning notice in the channel. Automatic warnings come only from moderator and admin clients, and the server hands each warning to exactly one of them, so a link is never warned twice.
  • 🔓 Override & Release: Immediately unquarantines a blocked link, marks it safe in the cache, and automatically removes its domain from blockedDomains so future links to that site aren’t blocked.
